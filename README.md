Experiments in AI-assisted development.

## Projects

### Flappy Bird (`index.html`, `style.css`, `game.js`)

A vanilla HTML5 Canvas Flappy Bird clone. No build step or dependencies.

**Run it:** open `index.html` in a browser, or serve the folder (`python3 -m http.server`).

**Controls:** `Space` / `Click` / `Tap` to flap · `Enter` or tap to restart after game over.
